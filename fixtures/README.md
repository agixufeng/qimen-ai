# 36 个完整对照盘

`reference-36.json` 是固定输入与字面量期望值，不会在运行产品测试时调用生成器更新。`WORKINGS.md` 提供每盘可读中间过程与九宫表。`build-reference.mjs` 保留独立构造记录，只依赖 `lunar-javascript`，没有 import、读取或调用 core 排盘实现。

## 证据等级与边界

这些盘是 **AI 辅助独立规则推演**，不是人工审定金标准，也不是从古籍或其他排盘软件抄录的外部完整盘。它能捕捉实现与约定规则的偏离；无法排除两份实现共同误解规则、历法依赖共同错误，不能据“36盘一致”声称整个奇门系统或占断已获验证。

历法事实仅取 `lunar-javascript 1.7.7`：真实公历日期、日干支、当前节气和交节时刻。时干由已批准的23时换日规则与五鼠遁独立计算。该库不提供这里的局数与各盘面期望。候选日期限定为2026年、固定UTC+8；不声称覆盖历史时区、真太阳时或其他流派。规则依据是本项目用户批准的 `shijia-zhuanpan-chaibu-v1`；古籍出处与流派争议应另见知识文档，不用此数据代替文献校勘。

## 覆盖

- 36盘：阳遁1—9局、阴遁1—9局，每局2盘；每对的日期、旬首不同。
- 六旬均有：甲子5、甲戌5、甲申5、甲午5、甲辰4、甲寅12盘。
- 上/中/下元分别13/12/11盘。
- 旬首原宫中五12盘；时干定位中五15盘；值使原数宫中五15盘。
- 星干与门盘外圈偏移均覆盖0—7全部8种。
- 每盘有9个地盘本干、9个天盘干、9星、8门、8神；中宫仅留地盘本干，坤宫另标寄入地干，天禽与天芮、相应两干共同转动。

中五值符保留身份：`chiefStar.origin=5` 且 `name=天禽`，以坤二为旋转锚点；值使 `origin=5`、`name=死门`，由数宫5推进，`rawPalace` 保留寄宫前结果。

## 一个展开核对示例

`yang-1-1` 输入2026-03-09 09:24 UTC+8：历法库给惊蛰、壬午日。符头己卯属于上元，惊蛰上元取阳一局；五鼠遁得乙巳时，甲辰旬遁壬。

地盘1至9依次戊己庚辛壬癸丁丙乙。旬首壬在5，值符天禽、值使死门；禽随芮，用坤2作星盘锚点。时干乙在9，芮禽双星及己壬两干从2移9；同向把其余星干整体转动。甲辰到乙巳相距1时，值使按数宫5顺行1步至6。八神由9起值符，顺外圈布列。这些步骤及所有其他宫位，均逐项保存在该例的 `provenance.workings`。
