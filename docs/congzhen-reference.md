## 项目中的落实

| 参考能力 | 本项目 v0.2 做法 | 可复核边界 |
| --- | --- | --- |
| 四柱空马 | 四柱分别查表；默认时空时马，日空日马可叠加 | 完整保留旬首、空支和马支，规则表公开 |
| 刑墓迫标识 | 天盘干旁逐个标刑墓，宫内显示门迫 | 标记可点开核对条件，不直接输出事件吉凶 |
| 十二长生 | 天地盘主寄干、宫内双支分别计算 | 阳顺阴逆土随火是项目选定规则，异说不混用 |
| 旺衰和内外盘 | 专业层显示星、门、宫的月令状态及内外盘 | 星气与正五行分表，标明月支及关系方向 |
| 显示开关 | 标准/专业层、日空日马、地盘参考 | 只改显示，不改基础盘和计算结果 |
| 暗干等更多参数 | 留作独立后续版本 | 不凭展示图推断其算法，也不在当前界面放无效入口 |

本项目采用自行设计的排版、文字图例和交互。手机端把详细参数放在宫位详情区，以免九宫格内字号过小；桌面可在盘旁阅读依据。目标是让参数可查、可解释、可复现，不要求与参考产品视觉一致。
