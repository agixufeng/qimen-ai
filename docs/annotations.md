# 辅助参数 shijia-common-annotations-v1 / 1.0.0

本文件定义项目 v0.2 的辅助分析取法。应用版本、基础排盘 profile、辅助 profile 分别保存；基础盘继续使用 `shijia-zhuanpan-chaibu-v1`。`analyzeChart(chart, annotationProfile)` 从已有盘面生成辅助结果，不修改定局与星门神位置。显示开关只筛选呈现，不能参与计算。

这是项目选定的一套执行规则，不能据此声称各流派一致、与从真内部算法相同，或预测效果得到验证。规则来源登记在知识包 `SOURCES`；未校影印的网页转录、仅作参考的链接与工程约定均明确区分。

**本版“长生入墓”与古籍三奇入墓条文存在明确差异。**本表乙墓戌；《烟波钓叟赋》公开转录的三奇入墓段又有乙临坤宫的取法。软件不得把两者混成同一规则，也不能仅因81组合格名包含“墓”字就标落宫入墓。长生参考链接本次读取失败，尚未复核该网页原文；执行真源是以上用户批准的明确表，不宣称已完成原书校勘。

所有天盘、地盘主干与寄干都保留身份和实际落宫。四维宫按两支分别列状态，例如癸在坤宫显示“未：墓／申：死”；不会把整宫简写成同一个长生状态。中5原位无支，不计算长生或入墓；寄出的干按寄入位置计算。旬首隐甲不额外作为可见天干加入盘面。

## 4. 界面、存盘与解释边界

- 标准盘显示宫支、时空、时马，以及天盘各干旁的刑、墓；专业层可展开十二长生、九星/八门/宫位月令状态、内外盘和地盘参考。
- 点符号查看该项对象、输入条件、规则版本与来源；点宫内空白查看全宫。信息不只依赖颜色，空、马、刑、墓可并列显示。
- 新 JSON 保存基础盘、辅助 profile 与结果、显示选项；导入时分别检查基础和辅助一致性。旧版盘先核基础结果，再注明新增辅助层；旧记录不自动覆盖，另存生成新文档。
- SVG 按当前显示选项导出标记、图例和规则版本，默认不含占事备注。显示偏好保存在本机，不作为起局输入。

固定验收例为 2026-10-28 12:00:00 UTC+8，日乙亥、时壬午；时旬甲戌、空申酉，坤宫仅申空、兑宫酉空，时马申在坤，日马巳在巽；天盘癸在坤时列“未墓／申死”。该例用于核对当前明确规则，不是预测效果验证。

新增或更改取法须提供具体来源、差异说明和独立预期测试，并按影响更新辅助 profile 版本。基础排盘变更仍按基础 profile 规则处理。暗干、真太阳时、飞盘、置闰、多种寄宫和终身行运不在此辅助层中。
