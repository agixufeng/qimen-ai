# shijia-zhuanpan-chaibu-v1 / 1.0.0

本文件是本项目的明确约定，不宣称所有奇门流派一致。算法来源参照《神奇之门》中编“时家奇门演局的规律”“起局方法”“判断依据”；中宫身份/显示/版本处理属于本项目明确约定。来源id见知识包。

## 时间与定局

1. 输入公历1900—2100年年月日时分秒，固定UTC+8标准时间。拒绝不存在的日期与非整数；不会悄悄顺延2月30日。
2. lunar-javascript 1.7.7的Solar.fromYmdHms接受上述墙上时间。getDayInGanZhiExact使用子初换日，getTimeInGanZhi随该日干取时干；getYearInGanZhiExact/getMonthInGanZhiExact按实际交节。
3. 原始公历日期不变。23点只改变干支日与符头，不把节气查询时间挪到次日。交节当天按库提供的秒级时刻，等于交节时刻归新节气。
4. 从有效干支日向前找到最近甲或己日为符头。符头支子午卯酉=上，寅申巳亥=中，辰戌丑未=下。节气切换即换相应节气的局表，不补置闰局。

## 九宫布盘

- 地盘：戊从局数对应宫开始，戊己庚辛壬癸丁丙乙依数宫1—9阳顺阴逆。
- 时辰旬首：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。
- 外围环：坎1→艮8→震3→巽4→离9→坤2→兑7→乾6，顺时针。
- 本位星：蓬1、任8、冲3、辅4、英9、芮2、柱7、心6、禽5。
- 本位门：休1、生8、伤3、杜4、景9、死2、惊7、开6。
- 旬首六仪原数宫决定值符星、值使门。旬首在5时保留值符天禽身份与origin=5，旋转锚点取坤2，值使取死门。
- 值符随地盘时干：甲时以该旬隐干代替甲，时干在5时目标按坤2。九星与所带奇仪整体沿外围环转移，始终天禽随天芮。地盘中五原干仍留在5宫，只把hostedEarthStems作为坤宫显示附注；天盘两干随芮禽同移。
- 值使随时支：从旬首实际数宫（含5）起，以该时距旬首的0—9步阳顺阴逆计数宫；到5先保留rawPalace=5，再寄坤2。其余七门从本位门序沿外围环转布。
- 八神：值符从值符星目标宫起；值符、螣蛇、太阴、六合、白虎、玄武、九地、九天阳顺阴逆沿外围环布置。

## 格局判据

| 规则 | 判据 | 粒度 |
|---|---|---|
| 星伏吟 | 外围八颗主星全部回本位；禽随芮，不单独判断禽的对宫 | 全盘 |
| 星反吟 | 外围八颗主星全部到本位对宫，1↔9、2↔8、3↔7、4↔6 | 全盘 |
| 门伏吟 | 八门全部回本位 | 全盘 |
| 门反吟 | 八门全部到本位对宫 | 全盘 |
| 门迫 | 门五行克所落宫五行 | 单宫 |

门五行：休水、生死土、伤杜木、景火、开惊金。只报告命中条件和来源，不把“凶格”写成现实事件必然发生。

## 81格与流派边界

知识表默认采用《神奇之门》，《御定奇门宝鉴·混合百神》作为独立对照，与布盘参考分开登记；每条说明其版本。天盘干在前、地盘干在后。一个宫有芮禽双干时分别展示组合，地盘寄干为附加关系，不覆盖地盘原干。

三胜宫的天乙定义、终身盘取天地日干、八宫行运不在v0.1自动解读范围。详见terminology.md。
