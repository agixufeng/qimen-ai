## 隔离安装

将packages目录下四个tgz同时安装到新Node工程；无需克隆monorepo或运行TypeScript构建：

```sh
npm install /下载目录/qimen-core-0.4.0.tgz /下载目录/qimen-knowledge-0.4.0.tgz /下载目录/qimen-cli-0.4.0.tgz /下载目录/qimen-cases-0.4.0.tgz
npx qimen chart --datetime 2026-10-28T12:00:00
```

首次安装core仍需从npm取得固定版本lunar-javascript；后续计算完全离线。发布包在隔离目录执行真实安装并验证输出；安装阶段允许获取依赖，不声称无缓存环境能离线下载依赖。
