# 术语与异说

## 天地盘与81组合

“乙加辛”表示同宫的天盘乙加地盘辛，不能与天盘辛加地盘乙互换。盘面必须显式显示“天盘”“地盘”，不能依赖字的上下位置猜测。

甲隐于六仪：甲子对应戊、甲戌对应己、甲申对应庚、甲午对应辛、甲辰对应壬、甲寅对应癸。九种可见干两两有序组合为81种；一张盘只出现其中一部分。首版知识表使用的具体文献版本和甲行列处理见 [来源登记](./sources.md)。

“克应”包括传统给组合赋予的关系与应事解释，不仅是五行相克。摘要是学习提示，不把古籍关于刑罚、病亡、家庭或性别的断语转写为用户现实事实。

## 伏吟、反吟与门迫

星伏吟与门伏吟分别看对应盘层的整体位置；局部同干并不能证明全盘伏吟。反吟同样应说明所检测的是星还是门，不把一宫冲对理解成全盘成立。

门迫按本项目规则判断门的五行克落宫的五行，区别于宫克门。检测输出要包含命中宫位、门名、五行关系与规则 ID。中宫保留原始数据，寄宫用于解释外围布盘；不能把天禽寄芮重复计作两次星命中。

## 值符不是单一对象名

值符星指某旬当值九星；八神值符是神盘位置。二者在本项目规则中关联排布，但数据中应保留不同对象。值使则指当值八门，不等于八神值符。不要仅凭界面写一个“符”就推定其所有含义。

## 三胜宫与“天乙”

需要辨别的两种说法包括“天乙等于值符落宫”以及“由值符落宫的本位星再找天盘落宫”。后者是对参考软件盘面结果的一种推测，尚无经过本项目核定的软件实现或明确传承原文。因此不把某张盘面的吻合写入计算规则，也不把推测当成软件源码事实。

《御定奇门宝鉴》的歌注、神机赋等条文使用天乙、直符、旬头甲等术语；它们在不同句子里的对象需要连同上下文核对。“三胜”相关兵事条文不能仅凭近代名词替换就转换成现代疗愈、攻击、胜利按钮。首版不计算三胜宫，不把“天乙”设置为未经版本限定的通用宫位字段。

后续如加入三胜模块，须先确定书目、版本、逐步取法、已知盘例以及与值符星/值符神的关系，并用单独规则 ID 发布。

## 终身盘的日干取法

本项目首版为问事排盘，不生成终身宫或命主宫。“出生已经过去，所以取地盘日干”尚未查到可确定作者、版本及完整操作规则的原文；仅有“日干落宫为本人”的概括也不足以单独证明必须取天盘或地盘。

“地盘看过去”是某些解释体系的时间取象，不能直接推导出生盘的用神规则。今后如支持出生盘，应要求具体传承明确指定：哪个时点起盘、本人用神取哪一盘层、甲日怎样处理、行运如何叠加。规则未定前不根据用户反馈临时切换宫位。

## 已约定与已证明

固定 UTC+8、23点换干支日、中五寄坤等属于首版可复现约定。对照盘可以验证程序是否遵守约定；它不能证明不同流派错误，也不能证明术数预测有效。来源状态、代码测试和现实经历验证应分别记录。
